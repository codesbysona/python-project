# python-project

This repository contains my Python programming assignment on Operators in Python, created using Google Colab.

📌 About the Project

The assignment demonstrates the use of different types of Python operators with simple examples and outputs. It was created to understand how operators are used in Python programming.

🧠 Topics Covered

- Arithmetic Operators
- Assignment Operators
- Comparison/Relational Operators
- Logical Operators
- Bitwise Operators
- Identity Operators
- Membership Operators
- Ternary Operator
- Operator Precedence

🛠️ Tools Used

- Python
- Google Colab
- GitHub

🎯 Purpose

The purpose of this assignment is to build a basic understanding of Python operators and learn how they are applied in different programming situations.

▶️ How to Run

The notebook can be opened and executed using Google Colab or Jupyter Notebook.
